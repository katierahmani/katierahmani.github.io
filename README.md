# Katie Rahmani — I-O Psychology Portfolio

A responsive, single-page portfolio website for showcasing industrial-organizational psychology projects. Built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Preview locally

Open `index.html` in a browser, or run a local static server from the repository root:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Personalize before publishing

- Replace `hello@example.com` with your preferred contact email.
- Update the LinkedIn link in the footer to your profile.
- Edit the project summaries and About copy to reflect your actual work and experience. The project cards are starter examples, not claims about completed client work.
- Add links to project case studies or downloadable materials as they become available.

GitHub Pages can publish this repository from its `main` branch after Pages is enabled in the repository settings.
